> 一款**完全离线**的 Android 摄影作品管理器：导入、分类、查看大图、读元数据、看 RAW。
> 无网络、无统计、无崩溃上报，所有数据只留在你自己的手机里。

## 二、核心特性

### 1. 完全离线
- **零联网**：清单里没有 `INTERNET` 权限，安装后不可能发出任何网络请求
- **零第三方 SDK**：没有统计、没有崩溃上报、没有广告
- 地理位置 → 行政区名称使用**内置离线行政区划库**（`assets/admin_cn.bin`）本地匹配，不上传坐标

### 2. 导入
- 从系统相册（MediaStore）导入；从文件管理（SAF）导入任意任意格式
- **默认复制**到 App 私有目录，不改动、不删除原文件；也支持"仅引用"模式
- 自动去重（同名 + 同大小）
- 导入前校验可用空间，不足会明确提示差多少
- Android 10+ 会申请 `ACCESS_MEDIA_LOCATION` 以读取**未脱敏**的原始 GPS

### 3. 浏览与查看
- 网格浏览、按日期/名称排序、筛选
- 大图查看：**双指缩放**、双击在「适应屏幕 ↔ 100%（像素点对点）」之间切换、左右滑动翻页
- 视频播放（含 HDR 色彩信息提示）
- 玻璃风格界面（顶栏为纯色面板，底栏为纯色胶囊，不做实时背景模糊——保证滚动帧率）

### 4. 相册
- 新建相册、从总相册挑图加入、从系统相册/文件导入加入
- 相册内与总相册一致的**长按多选 / 全选 / 删除**
- 「是否在总相册显示」开关（隐藏相册的照片不会出现在总相册；同一张照片若也属于可见相册则仍然显示）
- 相册内分享（系统分享面板）

### 5. 元数据（自研 EXIF 引擎）
不依赖系统 `ExifInterface`，自己实现容器定位 + TIFF 解析，因此能读到很多系统读不到的字段：

| 容器 | 支持 |
|---|---|
| JPEG | APP1 段 |
| TIFF / DNG | 原生 TIFF 结构 |
| HEIC / HEIF / AVIF | ISO-BMFF `meta/iinf/iloc` 解析 |
| PNG | `eXIf` 数据块 |
| CR2 / CR3 / NEF / ARW / RAF / ORF / RW2 等 | 厂商结构 + 通用 TIFF 扫描回退 |

展示内容：机型、镜头、焦段、光圈、快门、ISO、曝光补偿、拍摄时间、尺寸、方向、位置（经纬度 + 海拔 + 离线行政区）、以及 50 余项扩展标签。

### 6. 格式支持

**照片**：JPEG、PNG、AVIF、HEIC、TIFF（暂不支持 LZW 压缩的 TIFF）

**RAW**：内置 LibRaw 解码（JNI），支持厂商 RAW 的**内嵌预览**与**整幅解码**（按内存自适应降采样），缩略图与查看器共用同一套方向纠正逻辑。

**视频**：系统解码器支持的常见格式（H.264 / HEVC / AV1 等，取决于机型）

### 7. 已知限制（如实列出）
| 项 | 状态 |
|---|---|
| JPEG XL（.jxl） | **不支持全尺寸解码**，依赖系统解码器；部分 ROM（如 ColorOS）可显示 |
| OpenEXR（.exr） | 不支持解码 |
| LZW 压缩的 TIFF | 内置解码器未实现（支持未压缩 / PackBits / Deflate） |
| 乡镇街道级行政区 | 未内置，仅到区县 |
| 相册内拖拽排序 | 未实现 |

## 三、兼容项

| 项目 | 要求 |
|---|---|
| 最低系统 | **Android 10（API 29）** |
| 目标系统 | Android 16（API 36） |
| 架构 | **arm64-v8a**（正式包仅此一种） |
| 页面大小 | 支持 **16 KB** 页对齐（`zipalign -P 16`） |
| 权限 | `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`、`ACCESS_MEDIA_LOCATION`（可选） |
| 体积 | 约 36 MB |
| 隐私 | **无 `INTERNET` 权限**（已用 `aapt2 dump permissions` 验证） |

> 说明：`ACCESS_MEDIA_LOCATION` 若用户拒绝，App 仍可正常使用，只是导入的照片读不到 GPS（Android 会把位置抹掉）。

## 四、构建方法

### 环境
| 工具 | 版本 |
|---|---|
| JDK | 21 |
| Android SDK | compileSdk / targetSdk 36，build-tools 36.0.0 |
| NDK | 29.0.14206865（仅编译 JNI 时需要） |
| Gradle | 8.14.3（仓库自带 wrapper） |
| AGP / Kotlin | 8.13.2 / 2.3.21 |

### 步骤
```bash
# 1. 设置 SDK 路径（不要提交 local.properties）
echo "sdk.dir=/path/to/android-sdk" > local.properties

# 2. 构建 debug 包
./gradlew assembleDebug

# 3. 单元测试
./gradlew testDebugUnitTest
```

### 关于原生库
仓库中的 `app/src/main/jniLibs/{arm64-v8a,x86_64}/libraw.so` 是**预编译产物**，来自 **LibRaw 0.22.3**（LGPL-2.1）。
JNI 桥接源码在 `app/src/main/cpp/libraw_jni.cpp`，构建脚本见 `docs/BUILD_NATIVE.md`。
如需自行编译：下载 LibRaw 0.22.3 源码，用 NDK clang 编译静态库后与 `libraw_jni.cpp` 一起链接。

> 注意：工程路径需为纯 ASCII（AGP 对非 ASCII 路径支持有问题）。

## 十、目录结构

```
app/src/main/java/com/yingce/gallery/
├── data/        # Room 实体、DAO、导入器、系统相册访问
├── exif/        # 自研 EXIF 引擎（容器定位 + TIFF 解析 + HEIC/AVIF/PNG）
├── format/      # TIFF 像素解码器
├── raw/         # LibRaw JNI 封装、方向纠正
├── geo/         # 离线行政区匹配
└── ui/          # Compose 界面（网格、查看器、相册、详情面板、玻璃组件）
app/src/main/cpp/libraw_jni.cpp   # JNI 桥接
app/src/main/assets/admin_cn.bin  # 离线行政区划数据
```
